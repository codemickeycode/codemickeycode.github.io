# codemickeycode.com

The current static version of codemickeycode.com.

It uses plain HTML, CSS, and JavaScript. Open `index.html` directly for a basic preview, or serve this folder with any static file server before deployment. The shared header and footer are defined in `js/site-chrome.js`.

The landing page and additional About, Work, Notes, Life, and Contact pages are deployed from the repository root for GitHub Pages. The previous versions are preserved in `archive/`.
