# codemickeycode.com

The current static version of codemickeycode.com.

It uses plain HTML, CSS, and JavaScript. Open `index.html` directly for a basic preview, or serve this folder with any static file server before deployment.

The focused landing page is deployed from the repository root for GitHub Pages. The additional About, Work, Notes, Life, and Contact pages are available as future content and are intentionally not linked from the landing page yet. The previous root deployment is preserved in `archive_4/`.
